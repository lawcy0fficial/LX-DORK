## `01 // OVERVIEW`

**LX-DORK PRO** is a professional-grade, fully browser-native OSINT and Google Dorking framework designed specifically for authorized penetration testers, red teamers, and security researchers.

Unlike traditional dorking tools that are just lists of search strings, LX-DORK PRO is a **complete engagement workflow platform** — from initial target scoping, through systematic dork execution and result tracking, to professional report output ready for client delivery.

**No server. No install. No dependencies. Open `index.html` and operate.**

```
ARCHITECTURE PHILOSOPHY:

  Browser-Native ─────────────────────────── Zero server attack surface
  Single Folder ──────────────────────────── Portable, air-gap friendly
  3-File Split ───────────────────────────── Clean separation of concerns
  Zero Tracking ──────────────────────────── No telemetry, no callbacks
  All State In-Memory ────────────────────── Nothing persisted without you
```

### Dork Schema

Each dork entry in `lx-dork.js` follows this structure:

```javascript
{
  c:    'Category Name',           // Category (24 available)
  n:    'Dork Display Name',       // Short identifier
  q:    'site:{d} inurl:admin',    // Query template — {d} = injected target
  r:    'critical',                // Risk: critical | high | medium | low
  src:  'GHDB',                    // Source: GHDB | jhaddix | curated
  desc: 'What this finds and why'  // Plain-language description
}
```

**To add custom dorks**, append entries to the `D` array in `lx-dork.js`:

```javascript
{ c:'Admin Panels', n:'My Custom Dork', q:'site:{d} inurl:my-secret-path', r:'high', src:'custom', desc:'Finds my custom admin path.' },
```

  ext:           filetype:       cache:          link:

  AND            - (NOT)         " " (exact)     * (wildcard)

```

5. [ 💀 GOOGLE ] ─── Launch on Google
   [ 🌐 IN BROWSER ] ─── Open in integrated browser

  local category="${1:-all}"
  local base="https://raw.githubusercontent.com/danielmiessler/SecLists/master"
  echo -e "${CYAN}[*] Fetching wordlists — category: ${BOLD}${category}${NC}"
  mkdir -p "$WORDLIST_DIR"/{web-dirs,passwords,subdomains,fuzzing,dorks}

  declare -A lists=(
    ["web-dirs/common.txt"]="${base}/Discovery/Web-Content/common.txt"
    ["web-dirs/big.txt"]="${base}/Discovery/Web-Content/big.txt"
    ["web-dirs/raft-medium.txt"]="${base}/Discovery/Web-Content/raft-medium-directories.txt"
    ["web-dirs/api-endpoints.txt"]="${base}/Discovery/Web-Content/api/api-endpoints.txt"
    ["passwords/top-1k.txt"]="${base}/Passwords/Common-Credentials/10-million-password-list-top-1000.txt"
    ["passwords/top-10k.txt"]="${base}/Passwords/Common-Credentials/10-million-password-list-top-10000.txt"
    ["passwords/default-creds.csv"]="${base}/Passwords/Default-Credentials/default-passwords.csv"
    ["subdomains/top-5k.txt"]="${base}/Discovery/DNS/subdomains-top1million-5000.txt"
    ["subdomains/jhaddix-dns.txt"]="${base}/Discovery/DNS/dns-Jhaddix.txt"
    ["fuzzing/fuzz-bo0om.txt"]="${base}/Fuzzing/fuzz-Bo0oM.txt"
    ["fuzzing/lfi-linux.txt"]="${base}/Fuzzing/LFI/LFI-LFISuite-pathtotest.txt"
    ["fuzzing/sqli-payloads.txt"]="https://raw.githubusercontent.com/payloadbox/sql-injection-payload-list/master/Intruder/detect/Generic_SQLI.txt"
    ["fuzzing/xss-payloads.txt"]="https://raw.githubusercontent.com/payloadbox/xss-payload-list/master/Intruder/xss-payload-list.txt"
    ["dorks/google-dorks.txt"]="https://raw.githubusercontent.com/BullsEye0/google_dork_list/master/google_Dorks.txt"
  )

  local count=0
  for path in "${!lists[@]}"; do
    local url="${lists[$path]}"
    local file="$WORDLIST_DIR/$path"
    printf "  ${CYAN}Fetching${NC} %-42s" "$(basename $file)"
    if curl -sL --max-time 30 -o "$file" "$url" 2>/dev/null; then
      local lines=$(wc -l < "$file" 2>/dev/null || echo "?")
      echo -e "${GREEN}✓ ${lines} lines${NC}"
      ((count++))
    else
      echo -e "${RED}✗ failed${NC}"
    fi
  done
  echo -e "\n${GREEN}[+] Downloaded ${count}/${#lists[@]} wordlists → ${WORDLIST_DIR}/${NC}"
}

open_tool() {
  local html_path="$(pwd)/index.html"
  echo -e "${CYAN}[*] Opening LX-DORK PRO...${NC}"
  if command -v xdg-open &>/dev/null; then xdg-open "$html_path"
  elif command -v open &>/dev/null; then open "$html_path"
  elif command -v start &>/dev/null; then start "$html_path"
  else echo -e "${YELLOW}[!] Open manually: file://${html_path}${NC}"; fi
  echo -e "${GREEN}[+] Tool launched${NC}"
}

# ── Main ─────────────────────────────────
banner
check_deps

case "${2:-${1:-}}" in
  --help|-h)       usage ;;
  --wordlists)     setup_dirs; download_wordlists "all" ;;
  --subdomains)    download_wordlists "subdomains" ;;
  --passwords)     download_wordlists "passwords" ;;
  --fuzzing)       download_wordlists "fuzzing" ;;
  --dorks)         download_wordlists "dorks" ;;
  --setup)         setup_dirs ;;
  --open)          open_tool ;;
  *)               usage ;;
esac
```
